# Production Deployment Guide: Next.js + FastAPI + Firebase + AWS + Docker

Guide for running locally with Docker Compose or deploying to AWS ECS Fargate & CloudFront.

---

## 1. Local Containerized Execution

### Prerequisites
* Docker Desktop & Docker Compose installed
* Python 3.12+ / Node.js 20+ (for local development without Docker)

### Run Local Docker Cluster
```bash
# 1. Clone repository & configure environment variables
cp .env.example .env

# 2. Build and launch multi-stage containers
docker-compose up --build -d

# 3. Verify running containers
docker-compose ps
```

* **Frontend UI**: `http://localhost:3000`
* **FastAPI Backend Swagger Docs**: `http://localhost:8000/docs`
* **Backend Health API**: `http://localhost:8000/api/v1/health`

## 2. AWS Production Infrastructure Deployment

### Step A: Provision AWS Resources with Terraform
```bash
cd infrastructure/terraform

# Initialize Terraform
terraform init

# Review execution plan
terraform plan

# Apply infrastructure (ECR, VPC, ECS Cluster, S3 Bucket)
terraform apply -auto-approve
```

### Step B: Build & Push Images to AWS ECR
```bash
# Log in to ECR
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 123456789012.dkr.ecr.us-east-1.amazonaws.com

# Build and Push Backend Image
docker build -t 123456789012.dkr.ecr.us-east-1.amazonaws.com/autonomous-ai-analyst-backend:latest ./backend
docker push 123456789012.dkr.ecr.us-east-1.amazonaws.com/autonomous-ai-analyst-backend:latest

# Build and Push Frontend Image
docker build -t 123456789012.dkr.ecr.us-east-1.amazonaws.com/autonomous-ai-analyst-frontend:latest ./frontend
docker push 123456789012.dkr.ecr.us-east-1.amazonaws.com/autonomous-ai-analyst-frontend:latest
```

### Step C: Deploy ECS Fargate Task Definition
```bash
aws ecs register-task-definition --cli-input-json file://infrastructure/aws-ecs-task-def.json
aws ecs update-service --cluster autonomous-ai-analyst-cluster --service autonomous-ai-analyst-service --force-new-deployment
```

## 3. Security & Best Practices Checklist

1. **Environment Variables**: Never commit secrets to Git. Store secrets in **AWS Secrets Manager**.
2. **CORS Policy**: Configure `BACKEND_CORS_ORIGINS` in production to allow only your frontend domain.
3. **Firebase Authorization**: In production, pass valid Firebase ID tokens generated by `@firebase/auth` on client requests.
4. **HTTPS / SSL**: Attach ACM SSL Certificates to Application Load Balancer / Route53.
